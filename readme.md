## Инструкция
Проверьте наличие версии **Python** в терминале :
```text
python --version
python3 --version
py --version
```
Все файлы `.py` запускаются через терминал либо же через кнопку запуска в среде разработки :
```text
python "'полный или относительный путь к файлу с расширением .py'"
```
Например :
```text
python "C:\\Users\User\Desktop\file.py"
python "C:\Users\User\Desktop\file.py"
python "C://Users/User/Desktop/file.py"
python "C:/Users/User/Desktop/file.py"
```
'относительный путь' — путь относительно текущего рабочего каталога (директории) терминала.\
В некоторых IDE придётся вручную указывать запускаемый файл.
