## `debug.py`
</div>

<table>
<tr>
<th>Фрагмент А</th>
<th>Ожидаемый результат</th>
<th>Фактический результат</th>
<th>Причина ошибки</th>
</tr>
<tr>
<td>

```Python
first = "2"
second = "3"
print(first + second)
```
</td>
<td>

```text
5
```
</td>
<td>

```text
23
```
</td>
<td>

Значения "2" и "3" являются строками,\
поэтому оператор '+' соединяет их и дает "23",\
а не складывает.
</td>
</tr>
<tr>
<th>Исправленный фрагмент А</th>
<th></th>
<th></th>
<th>Решение</th>
</tr>
<tr>
<td>

```Python
first = 2
second = 3
print(first + second)
```
</td>
<td>

```text
5
```
</td>
<td>

```text
5
```
</td>
<td>

Преобразовать типы переменных в `int`.
</td>
</tr>
</table>

```text
Возраст: 17
```
</td>
<td>

```text
18
```
</td>
<td>


</td>
<td>

Преобразовать строку в целое число.


<th></th>

```Python
average = (first + second + third) / 3
print(average)
```
</td>
<td>

```text
7.0
```
</td>
<td>

```text
7.0
```
</td>
<td>

Нужно разделить на 3 всю сумму.
